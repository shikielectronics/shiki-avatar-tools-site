SHIKI Avatar Tools のインストール

製品に共通する VCC の導入手順

リポジトリを追加

VCC をインストールした PC で、SHIKI のパッケージリポジトリを追加します。ボタンで開けない場合は URL を手動で登録できます。

VCC インストールページを開く

プロジェクトに追加

VCC の Manage Project を開き、利用する SHIKI Avatar Tools のパッケージを選んで追加します。Unity の対応バージョンは各製品のガイドで確認してください。

β版を表示する

β版が見えない場合は Settings → Packages → Show Pre-Release Packages を有効にしてください。

SHIKI Avatar Tools 설치

모든 제품에 공통인 VCC 설치 방법

저장소 추가

VCC가 설치된 PC에서 SHIKI 패키지 저장소를 추가하세요. 버튼이 열리지 않으면 URL을 직접 등록할 수 있습니다.

VCC 설치 페이지 열기

프로젝트에 추가

VCC의 Manage Project에서 사용할 패키지를 선택해 추가하세요. Unity 버전은 각 제품 가이드를 확인하세요.

베타 버전 표시

베타 패키지가 보이지 않으면 Settings → Packages → Show Pre-Release Packages를 켜세요.

安装 SHIKI Avatar Tools

各产品通用的 VCC 安装步骤

添加软件源

在已安装 VCC 的电脑上添加 SHIKI 软件源。若按钮无法打开，可手动输入 URL。

打开 VCC 安装页面

添加到项目

在 VCC 的 Manage Project 中选择并添加所需软件包。请查看各产品指南了解支持的 Unity 版本。

显示测试版

如果找不到测试版，请开启 Settings → Packages → Show Pre-Release Packages。
