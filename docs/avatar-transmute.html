Avatar Transmute

Avatar Transmute を使い始めるための基本ガイド

GETTING STARTED

はじめに

Unity 2022.3 のアバタープロジェクトに VCC からパッケージを追加します。β版を導入する場合は、VCC の Settings → Packages → Show Pre-Release Packages を有効にしてください。

VCC インストール手順
WORKFLOW

基本的な作業の流れ

  1. 01
    アバターを診断

    元のアバターと衣装、表情、揺れ物の状態を確認します。

  2. 02
    必要な軽量化を選択

    メッシュや隠れ面の処理を設定し、変換結果をプレビューします。

  3. 03
    変換して検証

    用途に合わせて VRM 0.x / 1.0 を出力し、マテリアル・表情・ボーンの動作を確認します。

FEATURES

変換できるもの

  • 表情、揺れ物、コライダー
  • lilToon から MToon へのマテリアル変換
  • 不要メッシュや隠れ面の整理
  • 他の Editor 拡張から呼び出す公開 API
BEFORE EXPORT

変換前の確認

β版では変換前にプロジェクトをバックアップし、出力後に衣装の追従、表情、透明部分、揺れ物とコライダーを実機で確認してください。
